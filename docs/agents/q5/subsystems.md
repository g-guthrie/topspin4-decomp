## Method

- Call graph: `bl` targets and branches leaving the function (tail calls), from the pickled disassembly or raw words; `bctrl` counted only.
- Scope: gameplay ranges + slots of vtables loaded by gameplay functions + transitive direct callees that are game code. Middleware (decomp_survey `sdk` buckets: Havok, FMOD, XDK/D3D/CRT, Bink), third-party libraries with public source (decomp_survey `lib` buckets: Lua, zlib, expat, libpng/libjpeg, trio) and the renderer (0x886E8000-0x88780000) are external leaves.
- Subsystems: names in docs/gameplay/*-symbols.csv and symbols.md anchor functions; address ranges with good locality are pinned; the interleaved core 0x8865A000-0x886C8000 is labelled by label propagation over call edges, vtable class membership and address neighbours; dependencies are grouped by address bucket (FP/VMX-heavy helpers -> `math`, container/string names -> `cont`).
- Levels: Tarjan SCCs over unmatched in-scope functions; level 0 = ready now. Equivalent and escalated functions count as unsolved (byte-exact only).
- Status: `python3 tools/q5_status.py --worklist v2` (per subsystem); next ready work: `python3 tools/q5_status.py --worklist v2 --next 20 --subsystem move`.
